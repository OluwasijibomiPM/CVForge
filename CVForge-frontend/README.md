# CVForge Frontend

React + Vite frontend scaffolded around the supplied `cvforge.jsx` component.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is `dist/`.

## Vercel

Framework Preset: Vite
Build Command: npm run build
Output Directory: dist
Install Command: npm install
Root Directory: .
